# 🌀 Modulo-Visualizer

Hier läuft `a % n` in sechs Ansichten – endlos. Wähle oben eine Ansicht, stelle mit dem Regler
das **Modul n** ein und beobachte, wie sich die Reste immer wiederholen. Mit **Pause** und
**+1** gehst du Schritt für Schritt.

</ClientOnly>

::: tip Beobachtungsaufträge
- **Tabelle:** Warum steht die `14` bei `n = 7` in der Spalte „Rest 0“? Welche Zahlen stehen
  noch darunter?
- **3D-Spirale:** Wie viele leuchtende Säulen gibt es bei `n = 5`? Und bei `n = 12`?
- **Modulo-Uhr:** Lies für `a = 23` und `n = 7` ab: Wie viele Runden, wie viele Schritte?
- **Multiplikationskreis:** Halte bei `f = 2.00` und `f = 3.00` an. Welche Formen erkennst du?
- **Pascal mod n:** Bei welchem Modul entsteht das Sierpinski-Dreieck?
- **Sägezahn:** Bei welchen x-Werten fällt die Kurve auf 0 zurück?
:::
