# Kapitel 2 · Für Einsteiger

Hier lernst du das Programmieren von Grund auf. Arbeite die Seiten **der Reihe nach** durch – jede
baut auf der vorigen auf.

## Inhalt

1. [Erste Schritte](./erste-schritte) – dein erstes Programm, Variablen, Kommentare
2. [Ausgabe mit `print()`](./ausgabe) – mehrere Werte, Rechnen, f-Strings
3. [Selektion](./selektion) – Entscheidungen mit `if` / `elif` / `else`
4. [while-Schleife](./while-schleife) – wiederholen, solange eine Bedingung gilt
5. [for-Schleife](./for-schleife) – jedes Element einer Folge abarbeiten
6. [Listen](./listen) – mehrere Werte in einer Variablen
7. [Funktionen](./funktionen) – eigene Bausteine mit `def` und `return`
8. [Eingabe mit `input()`](./eingabe) – **ganz zum Schluss**: Programme interaktiv machen

::: info Warum kommt `input()` erst am Ende?
Bis dahin stehen alle Werte fest im Code. Das ist beim Lernen ein Vorteil: Du siehst sofort, was
passiert, und musst nichts eintippen. Zum Ausprobieren änderst du einfach die Werte im Code-Fenster
und führst neu aus.
:::
