# Was ist ein Algorithmus? <Badge type="tip" text="Klasse 7/8" />

Ein Rezept für Pfannkuchen, eine Wegbeschreibung, eine Bauanleitung für ein Regal: Alle beschreiben **Schritt für Schritt**, wie man ein Ziel erreicht.

::: info Merke: Algorithmus
Ein **Algorithmus** ist eine **Handlungsanweisung** aus einzelnen Schritten, die in einer **klaren Reihenfolge** ausgeführt werden, um ein **Problem oder eine Aufgabe zu lösen**.
:::

(Das Wort hat übrigens nichts mit „Rhythmus“ zu tun. Es geht auf den persischen Mathematiker **al-Chwarizmi** zurück.)

## Algorithmen und das EVA-Prinzip

Ein Algorithmus beschreibt, **wie** aus einer Eingabe eine Ausgabe wird:

```text:no-line-numbers
Eingabe ──► Algorithmus (Verarbeitung) ──► Ausgabe
Zutaten     Rezept                          Pfannkuchen
```

(→ [EVA-Prinzip](../technische-informatik/eva-prinzip))

## Maschinen interpretieren nicht

::: info Aufgabe: Der Papierflieger-Roboter
Deine Sitznachbarin oder dein Sitznachbar spielt einen Roboter, der **nur genau das tut, was du aufgeschrieben hast**.
1. Schreibe einen Algorithmus, mit dem der Roboter einen Papierflieger faltet.
2. Lies ihn Schritt für Schritt vor, **ohne ihn zu verändern**. Der Roboter faltet.
3. Sieht das Ergebnis aus wie geplant? Wo war deine Anweisung **ungenau**?
:::

::: info Aufgabe: Bilddiktat
Beschreibe eine Zeichnung so genau, dass dein Partner sie **Rücken an Rücken** nachzeichnen kann, ohne sie zu sehen. Vergleicht danach.
:::

::: warning Merke
Menschen füllen Lücken mit ihrer Erfahrung: „Nimm ein Blatt“, aber welches? Eine **Maschine kann nicht interpretieren**. Deshalb müssen Algorithmen **eindeutig** sein.
:::
