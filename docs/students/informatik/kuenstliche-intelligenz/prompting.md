# Prompting <Badge type="tip" text="Klasse 9" />

Ein Sprachmodell antwortet auf das, was du eingibst. Ein **guter Prompt** (die Eingabe) sorgt für eine brauchbare Ausgabe, ein vager Prompt für eine vage Antwort. Das ist wieder das [EVA-Prinzip](../technische-informatik/eva-prinzip).

## Bausteine eines guten Prompts

| Baustein | Frage | Beispiel |
|---|---|---|
| **Rolle** | Aus welcher Sicht soll die KI antworten? | „Du bist Deutschlehrer:in in Klasse 9.“ |
| **Kontext** | Was muss die KI wissen? | „Ich schreibe eine Erörterung zum Thema Handyverbot an Schulen.“ |
| **Aufgabe** | Was genau soll passieren? | „Nenne mir Gegenargumente zu meiner These, keine fertigen Absätze.“ |
| **Format** | Wie soll das Ergebnis aussehen? | „Als Tabelle mit Argument, Beispiel und möglicher Entkräftung.“ |
| **Beispiele** | Wie sieht ein gutes Ergebnis aus? | „So soll ein Argument aussehen: …“ |
| **Grenzen** | Was soll die KI **nicht** tun? | „Erfinde keine Studien. Sag, wenn du etwas nicht weißt.“ |

::: tip Nachfragen und verbessern
Ein Prompt muss nicht beim ersten Mal perfekt sein. Frage nach („Begründe Punkt 2 genauer“), korrigiere („Das ist zu lang, fasse in drei Sätzen zusammen“) oder lass dir die Aufgabe **schrittweise** lösen.
:::

::: warning Immer prüfen
- Sprachmodelle können **Fakten, Quellen und Zitate erfinden**. Prüfe wichtige Aussagen mit verlässlichen Quellen.
- Gib **keine persönlichen Daten** (von dir oder anderen) in KI-Tools ein.
- Beachte die Regeln deiner Schule zur Nutzung von KI bei Hausaufgaben und Leistungen.
:::

## Aufgabe

Erarbeite dir mit [Informatikbuch: Prompting](https://buch.informatik.cc/ki/prompting) weitere Prompt-Strategien und probiere sie in einem KI-Tool aus. Vergleiche die Antwort auf einen **kurzen** Prompt mit der Antwort auf einen Prompt, der alle Bausteine nutzt.
