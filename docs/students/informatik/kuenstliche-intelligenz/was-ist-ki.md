# Was ist KI? <Badge type="tip" text="Klasse 9" />

Ist ein Taschenrechner intelligent? Eine Krähe, die Nüsse auf die Straße legt, damit Autos sie knacken? Ein Schachcomputer? Ein Chatbot?

## Was ist Intelligenz?

Es gibt keine allgemein anerkannte Definition. In unseren Klassen wurden immer wieder diese Merkmale genannt:
- **Probleme lösen**, auch komplexe
- **aus Erfahrung lernen**
- sich an **neue Situationen anpassen**
- **Zusammenhänge erkennen**
- Wissen **aufnehmen, speichern und anwenden**
- über das eigene Handeln **nachdenken**

::: info Merke
Intelligenz beschreibt die **geistige Leistungsfähigkeit**, besonders beim **Lösen von Problemen**, bei Menschen und in Teilen auch bei Tieren.
**Künstliche Intelligenz** nennt man Computersysteme, die Aufgaben lösen, für die Menschen üblicherweise Intelligenz brauchen.
:::

## Schwache und starke KI

| Schwache KI | Starke KI |
|---|---|
| ist auf **einen Bereich** spezialisiert | würde in **allen Bereichen** so gut zurechtkommen wie ein Mensch |
| Schachprogramm, Gesichtserkennung, Übersetzer | existiert (noch) **nicht** |

Darüber hinaus spricht man von **Künstlicher Superintelligenz**, einer hypothetischen KI, die dem Menschen in allem überlegen wäre.

::: details Diskussion: Ist ChatGPT eine starke KI?
ChatGPT kann über fast jedes Thema schreiben. Das wirkt „allgemein“. Aber: Es erzeugt Texte, indem es wahrscheinliche Fortsetzungen berechnet. Es kann nicht selbstständig handeln, hat kein echtes Verständnis der Welt und macht leicht überprüfbare Fehler. Die meisten Fachleute zählen solche Systeme deshalb zur **schwachen KI**. Wie siehst du das?
:::

## KI oder „normaler“ Algorithmus?

| Klassischer Algorithmus | KI-System (maschinelles Lernen) |
|---|---|
| Verhalten ist **vollständig vom Menschen programmiert** | Verhalten wird aus **Daten trainiert** |
| feste Regeln, gleiche Eingabe → **gleiche Ausgabe** | Ergebnisse oft **wahrscheinlichkeitsbasiert** |
| passt sich **nicht** an | kann sich an **neue Daten anpassen** |
| Sortierverfahren, Passwortprüfung | Spam-Filter, Bilderkennung |

::: info Merke: Unsere Unterscheidung
Wird die Lösung **explizit programmiert** oder **aus Daten gelernt**?
Wir nennen ein System KI, wenn es sein Verhalten **auf Basis von Daten verändert**, ohne dass alle Regeln einprogrammiert wurden.
:::
