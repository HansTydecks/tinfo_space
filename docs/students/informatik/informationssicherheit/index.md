# Informationssicherheit

Wem kannst du im Netz vertrauen? Wie schützt du deine Daten vor Fremden, und wie kommt eine Nachricht an, ohne dass jemand mitliest? In diesem Kapitel geht es um **Datenschutz, Datensicherheit und Kryptographie**, vom sicheren Passwort bis zum RSA-Verfahren.
