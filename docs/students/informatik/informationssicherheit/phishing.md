# Phishing <Badge type="tip" text="Klasse 8" />

„Ihr Konto wurde gesperrt! Bestätigen Sie Ihre Daten innerhalb von 24 Stunden unter folgendem Link …“ Kommt dir das bekannt vor?

::: info Merke: Phishing
**Phishing** (von *Password Fishing*) bedeutet, dass Angreifer mit **gefälschten Nachrichten oder Websites** versuchen, an **persönliche Daten** zu kommen, etwa Passwörter, Kreditkartennummern oder Zugangsdaten.
:::

## Warnzeichen

| Hinweis | Beispiel |
|---|---|
| **Zeitdruck und Drohung** | „Innerhalb von 24 Stunden, sonst wird Ihr Konto gelöscht!“ |
| **Seltsamer Absender** | `support@paypa1-sicherheit.com` statt der echten Domain |
| **Link führt woanders hin** | Der angezeigte Text sagt `bank.de`, die Maus über dem Link zeigt `bank-login.xyz` |
| **Unpersönliche Anrede** | „Sehr geehrter Kunde“ statt deines Namens |
| **Abfrage sensibler Daten** | Seriöse Firmen fragen **nie** per E-Mail nach Passwort oder PIN |
| **Unerwartete Anhänge** | „Rechnung.zip“ oder „.exe“-Dateien |
| **Fehler** | Rechtschreibung, merkwürdige Übersetzungen (wird dank KI aber seltener!) |

::: warning Authentizität von Nachrichten
Der angezeigte Absendername einer E-Mail lässt sich **beliebig fälschen**. Dass eine Nachricht „von deiner Bank“ zu kommen scheint, beweist gar nichts.
:::

## So schützt du dich

1. **Nicht auf Links klicken**: Rufe die Website lieber selbst im Browser auf.
2. **Absender-Adresse und Link-Ziel genau prüfen** (Maus über den Link halten, ohne zu klicken).
3. **Nie Passwörter oder PINs** auf Anfrage per Mail oder Messenger herausgeben.
4. Im Zweifel **auf einem anderen Weg nachfragen**, z. B. bei der Bank anrufen.
5. **Zwei-Faktor-Authentifizierung** aktivieren: Selbst ein gestohlenes Passwort reicht dann nicht (→ [Authentifizierung](./authentifizierung)).

## Übung

Arbeite dich durch die Level von [Phishing Master](https://phishing-master.secuso.org/) (Sprache auf Deutsch stellen). Sammle dabei in deinem Hefter:
- Hinweise auf Phishing
- Regeln, um dich zu schützen
