# Informatiksysteme <Badge type="tip" text="Klasse 7" />

Der Wecker auf dem Handy klingelt, die Kaffeemaschine startet per App, an der Bushaltestelle zeigt eine Anzeige die Abfahrtszeit, und im Supermarkt piept der Scanner. Überall arbeiten **Informatiksysteme**.

::: info Merke: Informatiksystem
Ein **Informatiksystem** ist ein Gerät oder ein Verbund aus mehreren Geräten, das **Daten und Informationen verarbeitet**. Es besteht immer aus **Hardware** und **Software**.
:::

## Hardware und Software

| Hardware | Software |
|---|---|
| alles, was man **anfassen** kann | alles, was man **nicht anfassen, aber benutzen** kann |
| Geräte und Bauteile | Programme und Apps, die auf der Hardware laufen und sie steuern |
| Prozessor, Bildschirm, Tastatur, Kabel | Betriebssystem, Browser, Spiele, Messenger |

Hardware ohne Software ist nutzlos, und Software braucht Hardware, auf der sie laufen kann.

## Informatiksysteme im Alltag

| Informatiksystem | Beispiel für Hardware | Beispiel für Software |
|---|---|---|
| Smartphone | Touchscreen, Kamera, Akku | Betriebssystem, Kamera-App |
| Personalcomputer | Tastatur, Prozessor, Festplatte | Textverarbeitung |
| Einplatinenrechner (z. B. Calliope mini) | LED-Matrix, Knöpfe, Sensoren | dein eigenes Programm |
| Supermarktkasse | Barcodescanner, Kassenbondrucker | Kassenprogramm |

## Aufgabe

Beim Vorlesen einer Alltagsgeschichte notierst du jedes Informatiksystem, das vorkommt. Wie viele findest du? Ordne jeweils ein Beispiel für Hardware und Software zu.
