# Technische Informatik

Warum rechnet ein Computer so viel schneller als wir, obwohl er eigentlich nur **Strom an** und **Strom aus** kennt? In diesem Kapitel geht es vom Aufbau eines Informatiksystems über **Binärzahlen** bis hinunter zu **Transistoren, Schaltnetzen und der Architektur** moderner Rechner.
