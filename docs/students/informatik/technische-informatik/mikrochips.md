# Mikrochips <Badge type="info" text="Oberstufe" />

Ein moderner Prozessor ist kleiner als eine Briefmarke und enthält Milliarden Transistoren. Wie baut man so etwas?

::: info Merke: Vom Sand zum Chip
1. **Rohstoff Silizium:** gewonnen aus Quarzsand, dann extrem rein aufbereitet.
2. **Einkristall:** Aus geschmolzenem Silizium wird ein großer, perfekter Kristallzylinder gezogen.
3. **Wafer:** Der Kristall wird in hauchdünne runde **Scheiben** gesägt und poliert.
4. **Fotolithografie:** Schicht für Schicht werden die Strukturen der Schaltung mit Licht auf den Wafer „belichtet“, dann geätzt und mit Fremdatomen dotiert.
5. **Zerteilen und Testen:** Aus einem Wafer entstehen viele einzelne **Chips (Dies)**, die geprüft und in ein Gehäuse eingesetzt werden.
:::

::: tip Warum ein Reinraum?
Die Strukturen sind nur wenige **Nanometer** breit, viel kleiner als ein Staubkorn. Ein einziges Staubteilchen kann einen Chip unbrauchbar machen. Deshalb arbeiten Menschen in Chipfabriken in Schutzanzügen in **Reinräumen**.
:::

::: tip Sachsen und Chips
Rund um Dresden liegt eines der größten Mikroelektronik-Zentren Europas, oft „**Silicon Saxony**“ genannt.
:::
