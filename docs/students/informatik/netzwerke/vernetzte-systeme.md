# Vernetzte Systeme <Badge type="tip" text="Klasse 8" />

Dein Smartphone, der Schulrechner, die Spielkonsole und der Fernseher im Wohnzimmer haben etwas gemeinsam: Sie sind mit anderen Geräten verbunden und tauschen ständig Daten aus.

::: info Merke: Vernetztes System
Ein **vernetztes System** besteht aus mehreren Informatiksystemen, die miteinander verbunden sind, um **Daten, Informationen und Ressourcen gemeinsam zu nutzen**. Die Verbindung kann über Kabel oder über Funk (z. B. WLAN) laufen.
:::

## Wie kommunizieren Rechner?

Schau dich im Computerraum um: Von jedem Rechner führt ein Kabel zu einem Verteiler. Außerhalb des Raumes geht es weiter, über Router der Schule bis ins Internet.

- Geräte schicken sich **Datenpakete** zu, entweder über Kabel oder per Funk.
- Jedes Paket braucht eine **Adresse**, damit es beim richtigen Gerät ankommt (→ [Adressen & E-Mail](./adressen-und-e-mail)).

**Beispiel:** Du öffnest ein Video.
1. Dein Gerät schickt eine **Anfrage** an das Videoportal: „Schick mir dieses Video!“
2. Der Rechner des Portals **antwortet** mit den Videodaten.

## Client und Server

| | 🟢 Client | 🔵 Server |
|---|---|---|
| Aufgabe | **stellt Anfragen** | **beantwortet Anfragen** und stellt Daten bereit |
| Beispiel | Browser auf deinem Handy, Messenger-App | Webserver einer Nachrichtenseite, Mailserver |

::: tip Gut zu wissen
Ein Server ist nicht unbedingt ein großer Rechner in einer Halle. Ein Server ist zunächst ein **Programm**, das Anfragen beantwortet. Oft läuft es auf Rechnern, die genau dafür gebaut wurden.
:::

::: warning Das Problem mit dieser Aufteilung
Wenn sehr viele Clients zentral auf **einen** Server angewiesen sind, passiert Folgendes: Fällt der Server aus, funktioniert für alle nichts mehr. Außerdem liegen dort sehr viele Daten an einer Stelle. Das ist praktisch, aber auch ein attraktives Ziel für Angriffe.
:::

## Aufgaben

1. Notiere drei Beispiele für Client–Server-Paare aus deinem Alltag. Halte jeweils fest, **welche Daten** angefragt und welche bereitgestellt werden.
2. Sammle Bedürfnisse, die du mit vernetzten Systemen erfüllst (Kommunikation, Unterhaltung, Lernen, …). Gibt es Bereiche deines Lebens, die gar nicht vernetzt sind?
