# Adressen & E-Mail <Badge type="tip" text="Klasse 8" />

Du möchtest deinem Freund Stefan eine Nachricht schicken, und zwar **nur** ihm. Dafür brauchst du etwas, das genau zu Stefan gehört: seine Handynummer, seine Postanschrift oder seine E-Mail-Adresse.

::: info Merke
Adressen in Netzwerken müssen **eindeutig** sein: Eine Adresse gehört zu genau einem Empfänger.
:::

## Aufbau einer E-Mail-Adresse

```text:no-line-numbers
max.muster  @  schule-beispiel  .de
└──┬─────┘  │  └──────┬──────┘  └┬┘
 Name /     │      Domain       Top-Level-
 Postfach   "at" = bei          Domain
```

- **Lokaler Teil** (vor dem @): das Postfach, z. B. ein Name
- **@**: gesprochen „at“, englisch für „bei“
- **Domain** (nach dem @): der Anbieter bzw. die Organisation, bei der das Postfach liegt
- **Top-Level-Domain**: die Endung, z. B. `.de`, `.com`, `.org`

## Aufbau einer Web-Adresse (URL)

```text:no-line-numbers
https:// www.beispiel.de /informatik/netzwerke
└─┬───┘ └─────┬───────┘ └────────┬──────────┘
Protokoll  Rechnername/Domain   Pfad zur Seite
```

## Eine gute E-Mail schreiben

Du wirst in deinem Leben zehntausende E-Mails lesen und tausende selbst schreiben. Eine E-Mail besteht aus:

| Feld | Bedeutung |
|---|---|
| **An** | Hauptempfänger:in, von dem oder der du etwas willst |
| **CC** (*carbon copy*) | bekommt eine Kopie zur Information, alle sehen, wer in CC steht |
| **BCC** (*blind carbon copy*) | bekommt eine Kopie, die anderen Empfänger **sehen das nicht** |
| **Betreff** | kurze, aussagekräftige Zusammenfassung des Anliegens |
| **Inhalt** | Anrede, Anliegen, Gruß |
| **Anhang** | optional: Dateien |

::: tip Ein guter Betreff …
- ist **kurz** und **konkret**: „Frage zur Hausaufgabe S. 34, Nr. 2“ statt „Hallo“
- lässt erkennen, **worum es geht**, ohne dass man die Mail öffnen muss
:::

::: warning BCC schützt Daten
Schreibst du an viele Menschen, die sich nicht kennen (z. B. an alle Eltern einer Klasse), dann gehören die Adressen in **BCC**. Sonst gibst du fremde E-Mail-Adressen weiter.
:::

## Aufgabe

Verfasse eine kurze E-Mail an zwei Mitschüler:innen: eine Person steht in **An**, eine in **CC**, deine Lehrkraft in **BCC**. Achte auf einen passenden Betreff.
