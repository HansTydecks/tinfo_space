# Netzwerke – Grundlagen <Badge type="tip" text="Klasse 9" />

::: info Merke: Netzwerk
Ein **Netzwerk** besteht aus **Elementen (Knoten)**, die über **Verbindungen (Kanten)** miteinander verbunden sind. Netzwerke nutzen wir, um **Ressourcen zu teilen**, zum Beispiel Informationen, Drucker oder einen Internetzugang.
:::

Das Internet ist ebenfalls ein Netzwerk, genauer ein riesiges **Netz aus Netzen**.

## Netzwerke nach Größe

| Abkürzung | Name | Reichweite | Beispiel |
|---|---|---|---|
| **PAN** | Personal Area Network | wenige Meter | Handy ↔ Bluetooth-Kopfhörer |
| **LAN** | Local Area Network | ein Gebäude/Grundstück | Heimnetz, Schulnetz |
| **WAN** | Wide Area Network | Städte, Länder, weltweit | Internet |

## Netzwerkkomponenten

| Gerät | Aufgabe |
|---|---|
| **Switch** | verbindet Geräte **innerhalb eines** Netzwerks miteinander |
| **Router** | verbindet **verschiedene** Netzwerke miteinander, z. B. Heimnetz ↔ Internet |
| **Access Point** | bindet Geräte **per Funk** (WLAN) ins Netzwerk ein |
| **Modem** | wandelt Signale der Leitung (z. B. DSL, Glasfaser, Kabel) in digitale Daten um |

::: tip Im Alltag
Die „Box“ zu Hause (z. B. eine FRITZ!Box) ist meist **alles in einem**: Modem, Router, Switch und Access Point.
:::

## Übertragungsmedien

- **Kabel**: Kupferkabel (Netzwerkkabel) oder Glasfaser. Stabil und schnell.
- **Funk**: WLAN, Bluetooth, Mobilfunk. Flexibel, aber störanfälliger.

## Client-Server und Peer-to-Peer

| Client-Server | Peer-to-Peer (P2P) |
|---|---|
| Ein **zentraler Server** stellt Dienste bereit, viele Clients fragen an. | Alle Geräte sind **gleichberechtigt**: Jedes kann anfragen und bereitstellen. |
| Beispiel: Website, Mailserver | Beispiel: Dateitausch zwischen Rechnern, manche Blockchain-Netze |
| Fällt der Server aus, geht nichts mehr. | Kein zentraler Ausfallpunkt, aber schwerer zu kontrollieren. |
