# Quizmaster

<ToolInfo id="analog-programming" />

Die digitale Steuerzentrale für das analoge Kartenspiel **„Variablen-Memory“**. Die Lernenden spielen mit echten Karten im Raum, die App am Whiteboard übernimmt nur das Drumherum.

## Funktionen

- Glücksrad, das bestimmt, was als Nächstes passiert
- Timer (30 Sekunden pro Runde)
- Variablen-Tracking für `x`, `y` und `score`
- Spielprotokoll mit Export
- Farbsystem für die Karten: von Grundlagen über `if`-Anweisungen zu schwierigeren Stufen

## Im Unterricht

Ein bewegter Einstieg in Variablen und Bedingungen – ganz ohne Rechner für die Lernenden. Gespielt wird mit echten Karten, die im Raum verteilt sind.
