# Schlosssimulation

<ToolInfo id="lock_simulation" />

Eine digitale Kombinations-Schloss-Simulation, bestens geeignet für Escape Rooms oder verschlossene digitale Inhalte. Wer keine physischen Schlösser hat, findet hier eine gute Alternative.

## Funktionen

- Ein bis vier Zahlenschlösser gleichzeitig
- Optionaler Timer mit Warnung bei der letzten Minute
- Eigene Texte für Begrüßung, Erfolg, abgelaufene Zeit und Hinweise

## Im Unterricht

Die Lösungszahl ergibt sich aus Rätseln deines Fachs – so wird jede Wiederholungsstunde zum Escape Room. Das Schloss läuft auf dem Beamer oder auf den Geräten der Gruppen.
