# Tiny Johnny

<ToolInfo id="tiny-johnny" />

**Vom Von-Neumann-Rechner zum Modellrechner Johnny** – ein interaktiver Lernpfad für die Sekundarstufe II. Die Leitfrage: *Woher weiß der Computer eigentlich, was er tun soll?*

## Aufbau

| Teil | Inhalt |
|---|---|
| Von-Neumann-Rechner | 10 Kapitel: EVA, Ein-/Ausgabe, Speicher und Speichertechnik, Cache, Bus, CPU – mit Simulationen |
| Tutorial | 14 Missionen, in denen Johnny Bauteil für Bauteil aufgebaut wird |
| Aufgaben | 20 Aufgaben mit Testfällen, gestuften Tipps und Musterlösung |
| Sandbox | Johnny mit allen Funktionen: Mikro-/Makroschritt, eigene Befehle, Bonsai-Modus |

## Im Unterricht

Der Simulator verhält sich exakt wie der bekannte Modellrechner Johnny 2.0 – gleicher Mikrocode, gleiche Grenzen, gleiche Dateiformate. Vorhandene `.ram`- und `.mc`-Dateien lassen sich also weiterverwenden. Die Inhalte liegen als Textdateien im Repository und können direkt auf GitHub angepasst werden.
