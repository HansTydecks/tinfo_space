# Phishing-Sax

<ToolInfo id="phishing-sax" />

Eine nachgebaute LernSax-Startseite, die zur „Passworterneuerung“ auffordert. Wer auf *Anmelden* klickt, landet nicht bei einem Login, sondern auf einer unübersehbaren Warnseite: **Das war ein Phishing-Angriff.**

Es werden **keine Daten abgefragt oder gespeichert** – die Seite enthält kein Eingabefeld für Zugangsdaten.

## Im Unterricht

- **Einsatz:** Einstieg in das Thema Phishing und Informationssicherheit.
- **Warnzeichen suchen:** Auf der Seite sind typische Merkmale versteckt – eine leicht abweichende Adresse (`lernnsax` statt `lernsax`), Rechtschreibfehler und die Aufforderung, sofort das Passwort zu erneuern. Die Lernenden sammeln sie im Anschluss.
- **Nachbesprechung:** Wer hat geklickt, und warum? Was hätte auffallen können?
