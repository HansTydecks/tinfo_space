# Fraktale

<ToolInfo id="fraktale" />

Rekursion Schritt für Schritt kennenlernen – visuell und interaktiv. Die Lernenden verändern den Code, bewegen den Schieberegler und beobachten, wie aus einfachen Regeln komplexe Muster entstehen.

## Inhalte

- **Fraktale erkunden:** Sierpinski-Dreieck, Koch-Schneeflocke, Peano- und Hilbert-Kurve
- **Theorie:** Was ist Rekursion, und wie unterscheidet sie sich von Iteration? Mit Visualisierung des Aufrufstapels (Call Stack)
- **Selbst ausprobieren:** geführte Tutorial-Schritte zu jedem Fraktal – Code ändern, ausführen, staunen

## Im Unterricht

Geeignet für die Einführung von Rekursion in der Oberstufe. Die Oberfläche gibt es auf Deutsch, Englisch, Ukrainisch, Französisch und Spanisch.
