# Binär-ASCII-Visualizer

<ToolInfo id="binary-ascii-visualizer" />

Interaktive Visualisierung von 8 Bits: Schalter, ASCII-Zeichen, Dezimalwert und Graustufen-Ansicht. Das Tool ist für den Einsatz am Smartboard gebaut und zeigt, dass dieselben Bits ganz unterschiedliche Bedeutungen haben können.

## Im Unterricht

- **Einsatz:** Bits und Bytes einführen; zeigen, wie dieselben 8 Bit als Zeichen, Zahl oder Farbe gelesen werden.
- **Aktivitäten:** Bit-Schalter-Experimente, Umwandlungsaufgaben, Vergleich der Darstellungsformen.
- **Differenzierung:** Zweierpotenzen, Stellenwerte, Binär-String und Graustufe lassen sich einzeln ein- und ausblenden.
- **Für die Vorführung:** Tastenkürzel lassen das Alphabet durchlaufen oder von 0 bis 255 zählen.

Verwandt: [Becimal](../becimal/) – Stellenwertsysteme ganz ohne ASCII.
