# Calliope-Kurs

<ToolInfo id="calliope" />

Eine Kursseite zum Einplatinenrechner Calliope mini. Programmiert wird im Browser mit [MakeCode](https://makecode.calliope.cc/).

## Kapitel

1. Die wichtigsten Komponenten des Calliope mini
2. Eingabe, Verarbeitung und Ausgabe am Einplatinenrechner
3. Algorithmische Abläufe beschreiben
4. Kleine Projekte

## Im Unterricht

Die Kapitel bauen aufeinander auf und eignen sich zum selbstständigen Durcharbeiten. Wer danach eine Geschichte programmieren möchte, macht mit [Hase & Schildkröte](../hase-und-schildkroete/) weiter.
