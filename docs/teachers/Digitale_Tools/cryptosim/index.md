# CryptoSim

<ToolInfo id="cryptosim" />

Eine interaktive Webseite zum Erlernen von Kryptographie. Alice will Bob eine Nachricht schicken – und Mallory versucht mitzulesen.

## Level

| Level | Thema | Verfahren |
|---|---|---|
| 1 | Symmetrische Verschlüsselung | Caesar-Chiffre |
| 2 | Asymmetrische Verschlüsselung | RSA |
| 3 | Hybride Verschlüsselung | Kombination aus beidem |
| 4 | Digitale Zertifikate | SHA-256-Hash, digitale Signatur |

## Im Unterricht

Die Level bauen aufeinander auf – von der Caesar-Chiffre bis zu Zertifikaten, wie sie jede HTTPS-Verbindung nutzt. Die Oberfläche gibt es auf Deutsch, Englisch, Ukrainisch und Spanisch.
