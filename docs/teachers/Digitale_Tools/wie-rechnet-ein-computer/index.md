# Wie rechnet ein Computer?

<ToolInfo id="wie-rechnet-ein-computer" />

Ein interaktives Lernmodul für den Informatikunterricht der Oberstufe. Es führt in vier Kapiteln von der Frage „Was sieht der Computer, wenn ich `13 + 7` eingebe?“ bis zum Halbaddierer und bereitet damit die Unterrichtseinheit zu Schaltnetzen, ALU und Prozessor vor.

## Kapitel

| # | Kapitel | Leitfrage |
|---|---|---|
| 1 | Bits & Zahlensysteme | Wie stellt ein Computer Zahlen dar? |
| 2 | ASCII & Unicode | Wie wird aus einer Zahl ein Zeichen? |
| 3 | Festkomma & Gleitkomma | Wie speichert ein Computer 3,75? |
| 4 | Von Bits zu Addierern | Wie kann ein Computer mit 0 und 1 rechnen? |

## Im Unterricht

Jeder Abschnitt folgt demselben Muster: kurze Erklärung → Interaktion → Aufgabe → erklärendes Feedback → Erkenntnis. Insgesamt gibt es 25 Lernabschnitte und 25 zufällig erzeugte Aufgabentypen mit Hinweis und Schritt-für-Schritt-Lösung – geeignet für selbstständiges Arbeiten im eigenen Tempo.
